REINFORCEMENT LEARNING / ESSENTIALS

强化学习算法 · 简版

一个算法，一张流程图。只讲学习信号、核心公式与更新方式。

01PPO02折扣 Vine03鲁棒 Vine04KL 步长05等时长 Vine06Mirrored ES07ARS

共同目标：降低单位物理时间的平均排队成本。

评价一段运行

J(θ)=∑tct∑tΔtt,F(θ)=−J(θ)

θ：策略参数；ct：第 t 个事件区间的累计排队成本；Δtt：该区间物理时长。成本 J 越小越好，回报 F 越大越好。

动作空间方法的探索方式（01—05）

y∼pθ=𝒩(uθ(s),σ2I),a=LP(y)

s：状态与历史；uθ：策略输出的调度效用；σ：探索强度；LP：可行动作投影。概率密度 pθ(y|s) 属于投影前变量 y。

动作方法对 log pθ 求导，参数搜索直接比较轨迹回报；都不需要对 LP 求导。以下为核心更新式，省略实现中的附加约束。

01 / ACTOR–CRITIC价值估计 → 动作优势

连续时间折扣 PPO GAE + clipped update

用 critic 估计未来价值，再用 GAE 判断动作好坏；PPO 限制新旧策略的概率比。

物理时间折扣
xt=Δttτ,γt=e−xtrt=−ctbτ·1−e−xtxt
TD 与 GAE
δt=rt+γtVφ(st+1)−Vφ(st)A^t=δt+γtλtA^t+1
最大化裁剪目标
Rt(θ)=pθ(yt|st)pold(yt|st)R¯t=clip(Rt,1−ε,1+ε)Lclip=𝔼[min(RtA^t,R¯tA^t)]

τ 为折扣时间常数，b > 0 为任务成本率尺度，λt 为 GAE 衰减，ε 为裁剪宽度。Vφ 拟合折扣回报；真正终止时后继价值置零，采样截断仍保留价值补尾。xt → 0 时奖励中的比值取极限 1。

关键：优势依赖 critic；优化的是折扣代理目标，不是直接对长期平均成本率求梯度。

02 / PAIRED BRANCHES真实分支差 → 动作优势

折扣 Vine 可选 critic 补尾

从同一状态分叉，只改变首次动作；之后恢复同一无噪声策略，直接比较后续回报。

单支折扣回报
Gz=∑k=0H−1(∏j=0k−1γz,j)rz,kDz=∏k=0H−1γz,k,z∈{+,−}
无尾 / 有尾优势
AMC=G+−G−Atail=AMC+D+V(s+,H)−D−V(s−,H)
策略梯度方向
g^=1N∑i=1NAi∇θlogpθ(yi|si)

此处 + 表示探索支、− 表示参考支，不表示正负扰动；r、γ 沿用 01。空乘积为 1，sz,H 为分支末状态，N 为分支样本数。A 作为固定权重，不穿过环境反传。

关键：相同事件数不等于相同物理时长；补尾是在用 critic 估计尚未运行的未来。

03 / ROBUST ADVANTAGE改变优势的权重

鲁棒 Vine 归一化 + 裁剪 + Adam

沿用分支回报差，但先统一任务尺度，再压低极端优势对更新的影响。

归一化与截尾
A~i=AMC,imax(|V|¯task,v0)Bi=clip(A~i,−q,q),wi=BiRMS(B)+ϵ
最大化锚定目标
L(θ)=1N∑i=1Nwilogpθ(yi|si)−βKref(θ)

q 为 |Ã| 的分位阈值；v0、ϵ > 0 防止除零；RMS 为均方根。w 在更新时固定；Kref 是采样状态上与冻结参考策略的平均 KL，β 控制锚定强度。

关键：裁剪与归一化改变了样本权重，不再是原始成本目标的无偏梯度。

04 / CONTROLLED STEP改变更新的距离

归一化梯度 + KL 步长控制 Vine / SGD-KL

保留鲁棒分支优势，不用 Adam 逐坐标缩放；沿完整梯度方向试走，再按新旧策略的 KL 调整步长。

试探参数
g=∇θL(θ),θ′=θ+ηg‖g‖
KL 与步长修正
K(η)=𝔼s[DKL(pold(·|s)‖pθ′(·|s))]η←ηκK(η)

L 沿用 03，η 为参数步长，κ 为目标 KL。缩放式利用 KL 的局部二次近似，缩放后需重新测量；零梯度不更新，零 KL 不直接相除。pold 是本轮旧策略，不是冻结参考策略。

关键：这是欧氏梯度方向上的距离控制，不是自然梯度，也不是标准 TRPO。

05 / EQUAL-TIME BRANCHES无 critic · 无折扣

等时长 Vine 固定物理时间的成本差

仍只改变首次动作，但两支运行相同物理时间 T；直接比较窗口成本，不预测窗口以后的回报。

窗口累计成本
Cz(T)=∫0Th⊤qz(v)dv
平均成本率优势
AT=C参考(T)−C探索(T)T

qz(v) 为分支 z 的队列长度向量，h 为各队列成本权重，v 为从分叉起计的物理时间。AT > 0 表示探索动作降低了窗口成本；将它作为 02 策略梯度中的优势。

关键：固定 T 时，累计成本差与成本率差只差常数；有限窗口仍不等于无限时域的长期目标。

06 / PARAMETER SEARCH整条轨迹评价参数

Mirrored ES 正负参数扰动

不只改一次动作，而是用两套扰动参数各跑完整轨迹；比较回报，更新中心参数。

扰动与配对平均
θi±=θ±σεi,εi∼𝒩(0,I)F¯i±=1K∑k=1KF(θi±;ξk)
梯度估计与更新
g^=12mσ∑i=1m(F¯i+−F¯i−)εiθ←θ+αg^

m 为方向数，K 为每方向的配对环境 seed 数，ξk 表示环境随机性，σ 为参数扰动强度，α 为学习率。F 是整段负成本率；若做任务尺度归一化，尺度须预先固定。

关键：一条轨迹内参数保持不变，动作仍随状态变化；基础式估计高斯平滑后目标的梯度，不需要 critic 或反向传播。

07 / SELECTED DIRECTIONS筛选方向 · 归一化回报

ARS Augmented Random Search

同样做正负参数扰动，但只保留表现较好的方向，并用回报标准差调整更新尺度。

选取 b 个方向
B=Topb{i:max(F¯i+,F¯i−)}
回报标准差
σF=Std{F¯i+,F¯i−:i∈B}
更新中心
θ←θ+αbσF∑i∈B(F¯i+−F¯i−)εi

B 为选中方向的索引集合，b = |B|；其余符号沿用 06。若 σF 为零则跳过更新，避免除零；这里的 b 是方向数量，不是 01 的任务成本尺度。

关键：ARS 多了方向筛选和回报标准化，不等同于基础 Mirrored ES 的无偏梯度估计。
